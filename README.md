# 🎓 Student Management System (GUI in Python)

This is a beginner-friendly **Student Management System** built using **Python** and **Tkinter GUI**.

It helps you:
- Add student records
- Search by student ID
- View all students in a clean table
- Save/load data from a text file
- Stylish and modern UI using `ttk` and colors

---

## ✨ Features

- 🎨 Beautiful GUI with styled buttons and color themes
- 📋 Add, View, Search, and Save student data
- 💾 File saving/loading (`students_gui.txt`)
- 💡 Uses Python OOP and data structures: `list`, `set`, `dict`
- ✅ Input validation for age and marks

---

## 🧠 Data Structures Used

- `List` – Stores all student objects
- `Set` – Prevents duplicate student IDs
- `Dictionary` – For fast ID search
- `Class` – Student class for encapsulation

---
